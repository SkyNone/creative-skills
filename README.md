# Creative Skills

这里收录我持续打磨、经过真实图片验证的创意型 AI Skills。

## 镜外生境 · Paint Beyond the Frame

> 保留镜头内的真实，让镜头之外长出同一世界的彩色想象。

「镜外生境」会将一张真实照片转化为横向 mixed-media 作品：左侧完整保留原始摄影，右侧向画框之外延伸一幕低饱和、有空气感的想象场景。

它不是普通扩图，也不是把照片描成线稿。它遵循一个核心原则：

> **继承世界规则，改变具体画面；保持语义呼应，避免形状复刻。**

[查看 Skill 核心文件](./paint-beyond-the-frame/SKILL.md) · [在 ChatGPT 中打开「镜外生境」](https://chatgpt.com/skills?skill_id=6a75a66a78fc8191b62db93546bdabc0)

### 它创造什么

| 区域 | 视觉职责 |
|---|---|
| 左侧真实摄影 | 保留原图比例、透视、人物或动物身份、摄影质感与关键细节 |
| 中间过渡 | 只在窄幅边缘用纸纤维、淡墨、色彩晕染和少量越界线条连接 |
| 右侧想象场景 | 延续同一地点、时间、天气、尺度和情绪，但重新组织空间与内容 |

右侧默认采用低饱和水彩、彩铅、淡粉彩或半透明水粉。色彩来自原照片，而不是随机配色；它会比摄影侧更浅、更柔、更有纸张感，但不会退化为黑白草稿。

### 核心能力

- **原图保护**：向右增加画布，不在原画布里压缩、拉伸或重排照片。
- **同境续写**：右侧像摄影机继续向右移动后看到的“下一幕”，仍属于同一世界。
- **主体唯一**：不复制照片中的人物、动物、建筑、作品或地标，不制造第二视觉中心。
- **彩色想象**：从原图提取 3–5 个颜色角色，保留光线、天气与空气感。
- **视觉平衡**：右侧信息密度略低于摄影侧，保留自然留白，避免堆满装饰元素。
- **窄缝融合**：让色彩先越过边界，再让少量线条和形状越界，保持真实与虚构的区别。
- **确定性护栏**：本地图片可通过脚本准备画布、恢复原片并逐像素验证保护区域。

### 适合这些照片

- 旅行、山野、海岸、城市街道与建筑
- 人物、家庭、动物与日常生活瞬间
- 室内空间、展览、咖啡馆与公共场所
- 有明确环境、光线、天气或空间纵深的摄影作品
- 希望保留真实主体，同时增加杂志感、叙事感和想象空间的图片

### 不适合这些需求

- 普通修图、美颜、换背景或删除物体
- 精确还原真实地貌的全景补全
- 把整张照片转成动漫、油画或黑白线稿
- 与原场景无关的奇幻世界或随机拼贴
- 要求右侧与左侧一样写实的照片级 outpainting
- 对原照片进行重新构图、重绘人物或改变身份特征

### 最简单的用法

上传一张照片，然后说：

> 用镜外生境处理这张照片。完整保留原图，向右扩展为同一地点、同一时刻的彩色想象场景，不复制主体，少文字、多留白。

也可以补充你想强调的方向：

> 用镜外生境处理。右侧延续照片里的秋日光线和林间纵深，以低饱和水彩和彩铅表现；加入一条通向远处的小径，但不要出现第二个主体。

如果想让 Skill 自主判断：

> 用镜外生境处理这张照片，先理解场景，再决定镜头之外最自然的下一幕。

### 工作方式

1. 识别照片的唯一主角、空间结构、光线、季节、材质和情绪。
2. 提炼“如果镜头继续向右，会看见什么”的续写命题。
3. 从原图提取空气色、环境中间色、冷暖对照色、点睛色和纸张高光色。
4. 按原图比例向右扩展画布，并锁定摄影区域。
5. 只在右侧及极窄中缝生成新的彩色想象场景。
6. 恢复并验证原片像素，检查主体唯一性、世界连续性和视觉重量。
7. 对实际出现的问题做一次针对性修正，而不是无方向地反复生成。

### 创作边界

右侧需要继承：

- 地点与环境逻辑
- 季节、天气、光线和空气
- 观看高度、透视、尺度与纵深
- 材质语言与情绪温度

右侧必须变化：

- 空间组织
- 物体组合
- 具体轮廓
- 局部叙事

右侧明确禁止：

- 复制主要人物、动物、建筑或地标
- 照描原图轮廓，机械延长山脊、墙面或树枝
- 生成同等强度的第二视觉中心
- 跳转到不属于原场景的地点或奇幻题材
- 用局部放大、图鉴、标本或散乱装饰填满画面

### 设计目标

「镜外生境」追求的不是无缝伪装成一张完整照片，而是让两种媒介共同构成一幅完整作品：

- 左边是真实发生过的世界；
- 右边是它可能继续生长出的世界；
- 二者有明确差异，却共享同一束光、同一片空气和同一种情绪。
